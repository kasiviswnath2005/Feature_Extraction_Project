# Anime Feature Extraction and Analysis

## Overview

This project focuses on feature extraction and exploratory data analysis (EDA) using an anime dataset. The analysis was performed using Python, NumPy, and Pandas in a Jupyter Notebook environment. The goal was to extract meaningful features from raw data and uncover interesting insights about anime ratings, episode counts, and running durations.

## Objectives

* Perform data cleaning and preprocessing
* Create new features from existing data
* Analyze anime ratings and episode statistics
* Extract useful insights through data exploration

## Features Implemented

* Created a new column for episode count analysis
* Generated a duration/timestamp feature
* Identified the highest-scoring anime
* Found the top 5 highest-rated anime
* Determined the anime with the maximum episode count
* Extracted the top 5 anime with the highest episode counts
* Analyzed the longest-running anime series

## Technologies Used

* Python
* NumPy
* Pandas
* Jupyter Notebook

## Key Learning Outcomes

* Data Cleaning and Preprocessing
* Feature Engineering
* Data Filtering and Sorting
* Exploratory Data Analysis (EDA)
* Working with Pandas DataFrames
* Insight Extraction from Real-World Datasets

## Conclusion

This project helped strengthen my understanding of feature extraction, data manipulation, and exploratory data analysis using Python. It demonstrates how raw data can be transformed into meaningful information using NumPy and Pandas.
